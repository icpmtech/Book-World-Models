Chapter 19 completed a full production platform for sentiment, news, and multi-source AI-driven finance signals. This chapter synthesizes every concept from the book into a single, self-perpetuating architecture: the **Infinite Discovery Engine**.

The central idea is deceptively simple:

> A World Model that continuously discovers, validates, and applies new rules about financial markets — and feeds every discovery back into its own latent representations — achieves a form of **infinite knowledge growth** about any topic in market finance.

This is not merely an incremental improvement to a trading system. It is an architectural philosophy: the World Model is never *finished*. Every market cycle, every regime shift, every new data source is an opportunity to discover something the model did not know before. The **rules loop runs forever**.

## Part I — The Infinite Loop Architecture

### From a Static Model to a Living Intelligence

Every system described in earlier chapters — the RSSM, the HFT engine, the Trader Agent, the Sentiment Platform — operates on a fixed model trained on historical data. When markets change, these models degrade until a human initiates a retraining cycle.

The Infinite Discovery Engine removes this human bottleneck entirely. It is an autonomous architecture in which:

1. **Market data flows in continuously** from all sources described in Chapters 16–19
2. **The World Model encodes each new observation** into its latent state z_t
3. **The Rules Engine mines the latent space** for previously unseen patterns
4. **Discovered patterns are validated** against out-of-sample data and statistical tests
5. **Validated rules are stored** in the Finance Knowledge Graph
6. **The World Model is updated** with new rules as conditioning inputs
7. **The loop repeats** — without interruption, without a stopping condition

The architecture is intentionally described as **infinite** because financial markets are non-stationary: new regimes, new instruments, new macro environments continuously create new patterns that no fixed model can anticipate.

![Infinite Discovery Engine — Finance World Model Loop](/img/infinite-discovery-loop.svg)

### The Architectural Insight: Rules as First-Class Citizens

Most machine-learning systems treat rules as outputs — something extracted from a trained model after the fact via SHAP or decision-tree approximation. The Infinite Discovery Engine inverts this:

| Approach | Role of Rules |
|---|---|
| Traditional ML | Rules are *post-hoc explanations* |
| Expert Systems | Rules are *manually encoded* and *static* |
| **Infinite Discovery Engine** | Rules are *continuously discovered*, *validated*, and *fed back as inputs* |

A rule in this system is a first-class data structure:

```python
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Optional

class RuleType(Enum):
    STATISTICAL   = "statistical"    # correlation, cointegration, seasonality
    CAUSAL        = "causal"         # A → B with time lag
    REGIME        = "regime"         # rule valid in specific regime
    CROSS_ASSET   = "cross_asset"    # rule spans multiple asset classes
    SENTIMENT     = "sentiment"      # text/sentiment driven rule
    LLM_ABDUCED   = "llm_abduced"    # hypothesis generated by LLM reasoning

@dataclass
class DiscoveredRule:
    """A validated, versioned finance rule stored in the Knowledge Graph."""
    rule_id:        str
    rule_type:      RuleType
    description:    str              # human-readable explanation
    condition:      str              # symbolic: "RSI(14) < 30 AND VIX > 25"
    prediction:     str              # what the rule predicts: "SPY +2.1% in 5 bars"
    asset_universe: list[str]        # tickers this rule applies to
    regime_tags:    list[str]        # ["bear", "high_vol"] if regime-conditional
    sharpe_oos:     float            # out-of-sample Sharpe ratio
    ic_score:       float            # information coefficient (−1 to 1)
    p_value:        float            # statistical significance
    discovery_date: datetime
    last_validated: datetime
    active:         bool = True
    version:        int  = 1
    parent_rule_id: Optional[str] = None   # lineage tracking
    metadata:       dict = field(default_factory=dict)
```

### Module 1 — Statistical Miner

Discovers classical quantitative relationships:

```python
import numpy as np
import pandas as pd
from scipy import stats
from statsmodels.tsa.stattools import coint, adfuller
from sklearn.feature_selection import mutual_info_regression
from typing import Generator

class StatisticalMiner:
    """
    Continuously mines price and factor data for statistical rules.
    Discovers correlations, cointegration pairs, and mutual information.
    """

    def __init__(self, min_ic: float = 0.05, max_pvalue: float = 0.01):
        self.min_ic   = min_ic
        self.max_pvalue = max_pvalue
        self.discovered: list[DiscoveredRule] = []

    # ── Correlation scanner ────────────────────────────────────────────
    def scan_correlations(
        self,
        returns: pd.DataFrame,           # columns = tickers
        lag_range: range = range(1, 21), # lags in bars
    ) -> Generator[DiscoveredRule, None, None]:
        """Yields rules for significant lead-lag correlations between assets."""
        tickers = returns.columns.tolist()
        for leader in tickers:
            for follower in tickers:
                if leader == follower:
                    continue
                for lag in lag_range:
                    shifted = returns[leader].shift(lag)
                    valid   = returns[[follower]].assign(leader=shifted).dropna()
                    r, p    = stats.pearsonr(valid["leader"], valid[follower])
                    ic      = self._compute_ic(valid["leader"], valid[follower])
                    if abs(ic) >= self.min_ic and p <= self.max_pvalue:
                        yield DiscoveredRule(
                            rule_id=f"corr_{leader}_{follower}_lag{lag}",
                            rule_type=RuleType.STATISTICAL,
                            description=(
                                f"{leader} leads {follower} by {lag} bars "
                                f"(IC={ic:.3f}, p={p:.4f})"
                            ),
                            condition=f"{leader}_return[t-{lag}] > 0",
                            prediction=f"{follower}_return[t] > 0",
                            asset_universe=[leader, follower],
                            regime_tags=[],
                            sharpe_oos=0.0,  # filled by validator
                            ic_score=ic,
                            p_value=p,
                            discovery_date=pd.Timestamp.now(tz="UTC"),
                            last_validated=pd.Timestamp.now(tz="UTC"),
                        )

    # ── Cointegration scanner ──────────────────────────────────────────
    def scan_cointegration(
        self,
        prices: pd.DataFrame,
        significance: float = 0.05,
    ) -> Generator[DiscoveredRule, None, None]:
        """Yields pairs-trading rules for cointegrated assets."""
        tickers = prices.columns.tolist()
        for i, t1 in enumerate(tickers):
            for t2 in tickers[i + 1:]:
                score, pval, _ = coint(prices[t1].dropna(), prices[t2].dropna())
                if pval <= significance:
                    yield DiscoveredRule(
                        rule_id=f"coint_{t1}_{t2}",
                        rule_type=RuleType.STATISTICAL,
                        description=f"Cointegrated pair: {t1} / {t2} (p={pval:.4f})",
                        condition=f"zscore({t1},{t2}) > 2.0",
                        prediction=f"spread mean-reverts within 20 bars",
                        asset_universe=[t1, t2],
                        regime_tags=[],
                        sharpe_oos=0.0,
                        ic_score=0.0,
                        p_value=pval,
                        discovery_date=pd.Timestamp.now(tz="UTC"),
                        last_validated=pd.Timestamp.now(tz="UTC"),
                    )

    @staticmethod
    def _compute_ic(factor: pd.Series, returns: pd.Series) -> float:
        """Rank information coefficient between a factor and forward returns."""
        return factor.rank().corr(returns.rank(), method="pearson")
```

### Module 2 — Machine Learning Rule Learner

Trains gradient-boosted trees and extracts rules from the learned decision surfaces:

```python
import xgboost as xgb
from sklearn.tree import export_text, DecisionTreeClassifier
from sklearn.model_selection import TimeSeriesSplit
from sklearn.inspection import permutation_importance

class MLRuleLearner:
    """
    Trains an XGBoost model on a rolling window and extracts
    interpretable trading rules from the most important splits.
    """

    def __init__(
        self,
        n_estimators: int = 200,
        max_depth:    int = 4,
        min_sharpe:   float = 0.5,
    ):
        self.n_estimators = n_estimators
        self.max_depth    = max_depth
        self.min_sharpe   = min_sharpe

    def fit_and_extract(
        self,
        features: pd.DataFrame,   # factor matrix at time t
        targets:  pd.Series,      # forward 5-bar return
        tickers:  list[str],
    ) -> list[DiscoveredRule]:
        """
        Walk-forward train/test split: train on first 80%, test on last 20%.
        Extract rules from shallow decision-tree approximation.
        """
        # Binarise target: 1 if return > 0 else 0
        y = (targets > 0).astype(int)
        tss = TimeSeriesSplit(n_splits=5)

        rules = []
        for train_idx, test_idx in tss.split(features):
            X_tr, X_te = features.iloc[train_idx], features.iloc[test_idx]
            y_tr, y_te = y.iloc[train_idx],        y.iloc[test_idx]

            model = xgb.XGBClassifier(
                n_estimators=self.n_estimators,
                max_depth=self.max_depth,
                use_label_encoder=False,
                eval_metric="logloss",
                verbosity=0,
            )
            model.fit(X_tr, y_tr, eval_set=[(X_te, y_te)], verbose=False)

            # Surrogate shallow tree for rule extraction
            surrogate = DecisionTreeClassifier(max_depth=3)
            surrogate.fit(X_tr, model.predict(X_tr))

            rule_text = export_text(surrogate, feature_names=list(features.columns))
            for line in rule_text.split("\n"):
                if "|---" in line and "class:" not in line:
                    condition = line.replace("|", "").replace("---", "").strip()
                    rules.append(DiscoveredRule(
                        rule_id=f"ml_tree_{hash(condition) & 0xFFFFFF:06x}",
                        rule_type=RuleType.STATISTICAL,
                        description=f"ML-extracted rule: {condition}",
                        condition=condition,
                        prediction="5-bar return > 0",
                        asset_universe=tickers,
                        regime_tags=[],
                        sharpe_oos=0.0,
                        ic_score=0.0,
                        p_value=0.05,
                        discovery_date=pd.Timestamp.now(tz="UTC"),
                        last_validated=pd.Timestamp.now(tz="UTC"),
                    ))
        return rules
```

### Module 3 — Causal Discoverer

Uses the PC algorithm and LiNGAM to find genuine causal relationships between market variables, not mere correlations:

```python
class CausalDiscoverer:
    """
    Applies causal structure learning to discover directional
    relationships in financial time series.
    Uses the PC algorithm for observational data.
    """

    def __init__(self, alpha: float = 0.05):
        self.alpha = alpha

    def discover_causal_graph(
        self,
        data: pd.DataFrame,   # stationary factor panel
    ) -> list[DiscoveredRule]:
        """
        Runs PC algorithm (via causal-learn) to infer a DAG.
        Each directed edge A → B becomes a DiscoveredRule.
        """
        try:
            from causallearn.search.ConstraintBased.PC import pc
            from causallearn.utils.cit import fisherz
        except ImportError:
            return []  # skip if causal-learn not installed

        data_np = data.dropna().values.astype(float)
        cg = pc(data_np, self.alpha, fisherz, verbose=False)

        columns = data.dropna().columns.tolist()
        rules: list[DiscoveredRule] = []

        for i, j, edge_type in self._extract_edges(cg):
            if edge_type == "directed":
                cause   = columns[i]
                effect  = columns[j]
                rules.append(DiscoveredRule(
                    rule_id=f"causal_{cause}_causes_{effect}",
                    rule_type=RuleType.CAUSAL,
                    description=f"Causal edge: {cause} → {effect}",
                    condition=f"{cause} increases",
                    prediction=f"{effect} increases (causal, not merely correlated)",
                    asset_universe=[cause, effect],
                    regime_tags=[],
                    sharpe_oos=0.0,
                    ic_score=0.0,
                    p_value=self.alpha,
                    discovery_date=pd.Timestamp.now(tz="UTC"),
                    last_validated=pd.Timestamp.now(tz="UTC"),
                    metadata={"causal_algorithm": "PC"},
                ))
        return rules

    @staticmethod
    def _extract_edges(cg) -> list[tuple[int, int, str]]:
        edges = []
        n = cg.G.graph.shape[0]
        for i in range(n):
            for j in range(i + 1, n):
                if cg.G.graph[i, j] == -1 and cg.G.graph[j, i] == 1:
                    edges.append((i, j, "directed"))
                elif cg.G.graph[j, i] == -1 and cg.G.graph[i, j] == 1:
                    edges.append((j, i, "directed"))
        return edges
```

### Module 4 — LLM Abductor

Uses a Large Language Model to generate novel hypotheses about market relationships that data-driven methods might miss — then immediately submits them for statistical validation:

```python
import json
import re
from openai import OpenAI

class LLMAbductor:
    """
    Uses an LLM to generate candidate financial rules via abductive reasoning.
    Each hypothesis is structured as a DiscoveredRule candidate
    and submitted to the Validator before being accepted.
    """

    SYSTEM_PROMPT = """You are a quantitative finance research assistant.
Your task: generate novel, testable hypotheses about market behaviour.
Each hypothesis must be a JSON object with keys:
  - condition: a precise, measurable trigger (e.g. "10Y-2Y yield spread < 0")
  - prediction: the expected outcome (e.g. "SPY falls > 5% within 60 trading days")
  - rationale: a 1-sentence causal explanation
  - asset_universe: list of tickers affected
  - regime_tags: list of regimes where this rule applies (or [])
  - rule_type: one of "statistical", "causal", "regime", "cross_asset", "sentiment"
Output a JSON array of 5 hypotheses."""

    def __init__(self, model: str = "gpt-4o", api_key: str | None = None):
        self.client = OpenAI(api_key=api_key)
        self.model  = model

    def generate_hypotheses(
        self,
        market_context: str,   # short description of current market state
        existing_rules: list[str],  # descriptions of already-known rules (avoid duplicates)
    ) -> list[DiscoveredRule]:
        """Query LLM for new hypotheses given current market context."""
        user_msg = (
            f"Current market context:\n{market_context}\n\n"
            f"Already-known rules (do not repeat):\n"
            + "\n".join(f"- {r}" for r in existing_rules[:20])
        )
        try:
            response = self.client.chat.completions.create(
                model=self.model,
                messages=[
                    {"role": "system", "content": self.SYSTEM_PROMPT},
                    {"role": "user",   "content": user_msg},
                ],
                temperature=0.7,
                response_format={"type": "json_object"},
            )
            raw = response.choices[0].message.content
            # Support both {"hypotheses": [...]} and plain array
            parsed = json.loads(raw)
            items  = parsed if isinstance(parsed, list) else parsed.get("hypotheses", [])
        except Exception:
            return []

        rules = []
        for item in items:
            try:
                rules.append(DiscoveredRule(
                    rule_id=f"llm_{hash(item['condition']) & 0xFFFFFF:06x}",
                    rule_type=RuleType.LLM_ABDUCED,
                    description=item.get("rationale", item["condition"]),
                    condition=item["condition"],
                    prediction=item["prediction"],
                    asset_universe=item.get("asset_universe", []),
                    regime_tags=item.get("regime_tags", []),
                    sharpe_oos=0.0,
                    ic_score=0.0,
                    p_value=1.0,    # must be validated before trust
                    discovery_date=pd.Timestamp.now(tz="UTC"),
                    last_validated=pd.Timestamp.now(tz="UTC"),
                    active=False,   # inactive until validated
                    metadata={"source": "llm_abduction", "model": self.model},
                ))
            except KeyError:
                continue
        return rules
```

### Knowledge Graph Implementation

```python
import sqlite3
import json
from pathlib import Path
from datetime import datetime, timezone

class FinanceKnowledgeGraph:
    """
    SQLite-backed knowledge graph for discovered finance rules.
    Supports rule storage, versioning, regime-conditional queries,
    and expiry of rules that no longer validate.
    """

    def __init__(self, db_path: str = "finance_knowledge.db"):
        self.db_path = db_path
        self._init_schema()

    def _init_schema(self) -> None:
        with self._conn() as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS rules (
                    rule_id       TEXT PRIMARY KEY,
                    rule_type     TEXT NOT NULL,
                    description   TEXT NOT NULL,
                    condition     TEXT NOT NULL,
                    prediction    TEXT NOT NULL,
                    asset_universe TEXT NOT NULL,  -- JSON list
                    regime_tags   TEXT NOT NULL,   -- JSON list
                    sharpe_oos    REAL NOT NULL,
                    ic_score      REAL NOT NULL,
                    p_value       REAL NOT NULL,
                    discovery_date TEXT NOT NULL,
                    last_validated TEXT NOT NULL,
                    active        INTEGER NOT NULL DEFAULT 1,
                    version       INTEGER NOT NULL DEFAULT 1,
                    parent_rule_id TEXT,
                    metadata      TEXT DEFAULT '{}'
                )
            """)
            conn.execute(
                "CREATE INDEX IF NOT EXISTS idx_active ON rules(active)"
            )
            conn.execute(
                "CREATE INDEX IF NOT EXISTS idx_type ON rules(rule_type)"
            )

    def _conn(self) -> sqlite3.Connection:
        return sqlite3.connect(self.db_path)

    # ── Write ──────────────────────────────────────────────────────────
    def upsert_rule(self, rule: DiscoveredRule) -> None:
        """Insert or update a rule (versioning on update)."""
        with self._conn() as conn:
            existing = conn.execute(
                "SELECT version FROM rules WHERE rule_id=?", (rule.rule_id,)
            ).fetchone()
            version = (existing[0] + 1) if existing else 1

            conn.execute("""
                INSERT OR REPLACE INTO rules VALUES (
                    ?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?
                )
            """, (
                rule.rule_id,
                rule.rule_type.value,
                rule.description,
                rule.condition,
                rule.prediction,
                json.dumps(rule.asset_universe),
                json.dumps(rule.regime_tags),
                rule.sharpe_oos,
                rule.ic_score,
                rule.p_value,
                rule.discovery_date.isoformat(),
                rule.last_validated.isoformat(),
                int(rule.active),
                version,
                rule.parent_rule_id,
                json.dumps(rule.metadata),
            ))

    # ── Read ───────────────────────────────────────────────────────────
    def query_active_rules(
        self,
        rule_type: RuleType | None = None,
        regime:    str | None = None,
        min_sharpe: float = 0.0,
        min_ic:     float = 0.0,
    ) -> list[DiscoveredRule]:
        """Return active validated rules, optionally filtered."""
        sql = "SELECT * FROM rules WHERE active=1"
        params: list = []
        if rule_type:
            sql += " AND rule_type=?";  params.append(rule_type.value)
        if min_sharpe:
            sql += " AND sharpe_oos>=?"; params.append(min_sharpe)
        if min_ic:
            sql += " AND ic_score>=?";   params.append(min_ic)

        with self._conn() as conn:
            rows = conn.execute(sql, params).fetchall()

        rules = [self._row_to_rule(r) for r in rows]
        if regime:
            rules = [r for r in rules if not r.regime_tags or regime in r.regime_tags]
        return rules

    def rule_count(self) -> int:
        with self._conn() as conn:
            return conn.execute("SELECT COUNT(*) FROM rules WHERE active=1").fetchone()[0]

    @staticmethod
    def _row_to_rule(row: tuple) -> DiscoveredRule:
        return DiscoveredRule(
            rule_id        = row[0],
            rule_type      = RuleType(row[1]),
            description    = row[2],
            condition      = row[3],
            prediction     = row[4],
            asset_universe = json.loads(row[5]),
            regime_tags    = json.loads(row[6]),
            sharpe_oos     = row[7],
            ic_score       = row[8],
            p_value        = row[9],
            discovery_date = datetime.fromisoformat(row[10]),
            last_validated = datetime.fromisoformat(row[11]),
            active         = bool(row[12]),
            version        = row[13],
            parent_rule_id = row[14],
            metadata       = json.loads(row[15] or "{}"),
        )
```

## Part IV — The Discovery Feedback Cycle

The feedback cycle is what transforms a collection of discovery modules into a **living intelligence**. It orchestrates the six-step loop described in the architecture overview.

![Discovery Feedback Cycle — Continuous Finance Intelligence](/img/discovery-feedback-cycle.svg)

### Rule Validator

```python
import warnings
from dataclasses import replace as dc_replace

class RuleValidator:
    """
    Validates candidate rules using walk-forward backtesting
    and statistical significance tests.
    """

    def __init__(
        self,
        min_sharpe:   float = 0.4,
        min_ic:       float = 0.03,
        max_pvalue:   float = 0.05,
        n_oos_splits: int   = 3,
    ):
        self.min_sharpe   = min_sharpe
        self.min_ic       = min_ic
        self.max_pvalue   = max_pvalue
        self.n_oos_splits = n_oos_splits

    def validate(
        self,
        rule:    DiscoveredRule,
        prices:  pd.DataFrame,     # OHLCV price data for rule.asset_universe
        factors: pd.DataFrame,     # factor values used in rule.condition
    ) -> DiscoveredRule | None:
        """
        Returns an updated rule with validated metrics,
        or None if the rule fails validation.
        """
        try:
            signal   = self._compute_signal(rule, factors)
            returns  = self._compute_forward_returns(prices, rule.asset_universe)
            sharpe   = self._walk_forward_sharpe(signal, returns)
            ic       = self._walk_forward_ic(signal, returns)
            pvalue   = self._compute_pvalue(signal, returns)
        except Exception:
            return None

        if sharpe < self.min_sharpe or abs(ic) < self.min_ic or pvalue > self.max_pvalue:
            return None

        return dc_replace(
            rule,
            sharpe_oos    = round(sharpe, 4),
            ic_score      = round(ic, 4),
            p_value       = round(pvalue, 6),
            last_validated= pd.Timestamp.now(tz="UTC"),
            active        = True,
        )

    def _compute_signal(self, rule: DiscoveredRule, factors: pd.DataFrame) -> pd.Series:
        """Evaluate rule.condition as a binary signal (simplified)."""
        # In production: parse rule.condition into an AST and evaluate it.
        # Here we use a random signal as a placeholder for illustration.
        with warnings.catch_warnings():
            warnings.simplefilter("ignore")
            np.random.seed(abs(hash(rule.rule_id)) % 2**31)
            return pd.Series(
                np.random.choice([-1.0, 0.0, 1.0], size=len(factors)),
                index=factors.index,
            )

    @staticmethod
    def _compute_forward_returns(prices: pd.DataFrame, tickers: list[str]) -> pd.Series:
        cols = [t for t in tickers if t in prices.columns]
        if not cols:
            return pd.Series(dtype=float)
        return prices[cols].mean(axis=1).pct_change(5).shift(-5)

    @staticmethod
    def _walk_forward_sharpe(signal: pd.Series, fwd_returns: pd.Series) -> float:
        aligned = signal.align(fwd_returns, join="inner")
        s, r    = aligned[0].dropna(), aligned[1].dropna()
        both    = s.index.intersection(r.index)
        s, r    = s[both], r[both]
        if len(s) < 30:
            return 0.0
        pnl = s * r
        return float(pnl.mean() / (pnl.std() + 1e-9) * np.sqrt(252))

    @staticmethod
    def _walk_forward_ic(signal: pd.Series, fwd_returns: pd.Series) -> float:
        both = signal.index.intersection(fwd_returns.index)
        if len(both) < 30:
            return 0.0
        return float(signal[both].rank().corr(fwd_returns[both].rank()))

    @staticmethod
    def _compute_pvalue(signal: pd.Series, fwd_returns: pd.Series) -> float:
        both = signal.index.intersection(fwd_returns.index)
        if len(both) < 30:
            return 1.0
        _, pval = stats.spearmanr(signal[both], fwd_returns[both])
        return float(pval)
```

## Part V — The Complete Infinite Discovery Engine

This is the top-level orchestrator that **runs the loop forever**, discovering new finance rules on every iteration.

```python
import time
import logging
from concurrent.futures import ThreadPoolExecutor

logger = logging.getLogger(__name__)


class InfiniteDiscoveryEngine:
    """
    The Infinite Discovery Engine for Finance World Models.

    Continuously:
      1. Fetches fresh market data
      2. Encodes the World Model latent state
      3. Runs all discovery modules in parallel
      4. Validates candidates
      5. Stores validated rules in the Knowledge Graph
      6. Updates World Model conditioning inputs
      7. Loops — indefinitely

    Every iteration grows the Finance Knowledge Graph.
    There is no stopping condition.
    """

    def __init__(
        self,
        knowledge_graph:     FinanceKnowledgeGraph,
        statistical_miner:   StatisticalMiner,
        ml_rule_learner:     MLRuleLearner,
        causal_discoverer:   CausalDiscoverer,
        llm_abductor:        LLMAbductor | None,
        validator:           RuleValidator,
        data_fetcher,        # callable() → (prices, factors, returns)
        world_model,         # callable(prices, rules) → latent_state
        loop_interval_sec:   int = 3600,   # run loop every hour
        max_candidate_batch: int = 100,
    ):
        self.kg                  = knowledge_graph
        self.stat_miner          = statistical_miner
        self.ml_learner          = ml_rule_learner
        self.causal              = causal_discoverer
        self.llm                 = llm_abductor
        self.validator           = validator
        self.data_fetcher        = data_fetcher
        self.world_model         = world_model
        self.loop_interval       = loop_interval_sec
        self.max_candidate_batch = max_candidate_batch
        self._iteration          = 0

    # ── Main loop ──────────────────────────────────────────────────────
    def run_forever(self) -> None:
        """Entry point. Blocks indefinitely."""
        logger.info("Infinite Discovery Engine starting. Loop runs forever.")
        while True:
            try:
                self._run_one_iteration()
            except Exception as exc:
                logger.error(f"Iteration {self._iteration} failed: {exc}", exc_info=True)
            self._iteration += 1
            logger.info(
                f"Iteration {self._iteration} complete. "
                f"Knowledge graph size: {self.kg.rule_count()} rules. "
                f"Sleeping {self.loop_interval}s."
            )
            time.sleep(self.loop_interval)

    # ── Single iteration ───────────────────────────────────────────────
    def _run_one_iteration(self) -> None:
        logger.info(f"── Iteration {self._iteration} ── Fetching data …")

        # Step 1: Observe
        prices, factors, returns = self.data_fetcher()

        # Step 2: Encode — update World Model latent state with current rules
        active_rules = self.kg.query_active_rules(min_sharpe=0.4, min_ic=0.03)
        latent_state = self.world_model(prices, active_rules)
        logger.info(f"  Latent state shape: {latent_state.shape if hasattr(latent_state, 'shape') else 'n/a'}")

        # Step 3: Discover — run all modules in parallel
        candidates: list[DiscoveredRule] = []
        with ThreadPoolExecutor(max_workers=4) as pool:
            stat_future   = pool.submit(self._run_stat_miner,   returns)
            ml_future     = pool.submit(self._run_ml_learner,   factors, returns)
            causal_future = pool.submit(self._run_causal,       factors)
            llm_future    = pool.submit(self._run_llm,          latent_state)

            for future in [stat_future, ml_future, causal_future, llm_future]:
                try:
                    candidates.extend(future.result())
                except Exception as exc:
                    logger.warning(f"Discovery module error: {exc}")

        logger.info(f"  Discovered {len(candidates)} candidate rules this iteration.")

        # Limit batch size to avoid validation bottleneck
        candidates = candidates[: self.max_candidate_batch]

        # Step 4: Validate
        validated  = 0
        for candidate in candidates:
            validated_rule = self.validator.validate(candidate, prices, factors)
            if validated_rule is not None:
                # Step 5: Store in Knowledge Graph
                self.kg.upsert_rule(validated_rule)
                validated += 1

        logger.info(f"  Validated and stored {validated} new rules.")

    # ── Module runners ─────────────────────────────────────────────────
    def _run_stat_miner(self, returns: pd.DataFrame) -> list[DiscoveredRule]:
        return list(self.stat_miner.scan_correlations(returns))

    def _run_ml_learner(
        self, factors: pd.DataFrame, returns: pd.DataFrame
    ) -> list[DiscoveredRule]:
        tickers = [c for c in returns.columns if c in factors.columns or True]
        target  = returns.mean(axis=1) if isinstance(returns, pd.DataFrame) else returns
        return self.ml_learner.fit_and_extract(factors, target, tickers)

    def _run_causal(self, factors: pd.DataFrame) -> list[DiscoveredRule]:
        return self.causal.discover_causal_graph(factors)

    def _run_llm(self, latent_state) -> list[DiscoveredRule]:
        if self.llm is None:
            return []
        context = f"World model latent norm={float(np.linalg.norm(latent_state)):.3f}"
        known   = [r.description for r in self.kg.query_active_rules()[:20]]
        return self.llm.generate_hypotheses(context, known)
```

```python
import yfinance as yf
import numpy as np
import pandas as pd

TICKERS = [

    "AAPL", "MSFT", "GOOGL", "AMZN", "NVDA", "TSLA",
    "JPM", "GS", "BAC", "C", "BRK-B",
]
LOOKBACK_DAYS = 504   # 2 years of daily bars
LOOP_INTERVAL = 3600  # re-run every hour


def fetch_market_data():
    """Fetch OHLCV data and build a simple factor matrix."""
    raw      = yf.download(TICKERS, period=f"{LOOKBACK_DAYS}d", progress=False)
    prices   = raw["Close"].dropna(how="all")
    returns  = prices.pct_change().dropna()

    # Simple factor set: momentum, volatility, RSI-like
    factors = pd.DataFrame(index=returns.index)
    for ticker in prices.columns:
        r = returns[ticker]
        factors[f"{ticker}_mom5"]  = r.rolling(5).mean()
        factors[f"{ticker}_mom20"] = r.rolling(20).mean()
        factors[f"{ticker}_vol20"] = r.rolling(20).std()
        # Simplified RSI
        gain = r.clip(lower=0).rolling(14).mean()
        loss = (-r).clip(lower=0).rolling(14).mean()
        factors[f"{ticker}_rsi14"] = 100 - (100 / (1 + gain / (loss + 1e-9)))

    return prices, factors.dropna(), returns


def simple_world_model(prices, rules):
    """
    Minimal world model: PCA on returns as a latent state proxy.
    In production, replace with the RSSM encoder from Chapter 8.
    """
    from sklearn.decomposition import PCA
    r = prices.pct_change().dropna()
    pca = PCA(n_components=min(8, r.shape[1]))
    latent = pca.fit_transform(r.fillna(0))
    # Condition on rule count as a simple scalar context
    rule_signal = np.array([[len(rules)]] * len(latent))
    return np.hstack([latent, rule_signal])


def main():
    # Instantiate all components
    kg        = FinanceKnowledgeGraph("finance_knowledge.db")

    engine.run_forever()
```
